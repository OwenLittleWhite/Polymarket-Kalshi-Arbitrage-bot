## 系统架构概览

### 核心设计理念

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                        Prediction Market Arbitrage Bot                       │
│                         (Kalshi-Poly / Poly-Poly)                           │
└─────────────────────────────────────────────────────────────────────────────┘
                                      │
        ┌─────────────────────────────┼─────────────────────────────┐
        │                             │                             │
        ▼                             ▼                             ▼
┌───────────────┐           ┌───────────────┐           ┌───────────────┐
│  Kalshi API   │           │ Polymarket    │           │ Global State  │
│  + WebSocket  │           │ CLOB API      │           │   (Atomic)    │
└───────────────┘           └───────────────┘           └───────────────┘
        │                             │                             │
        └─────────────────────────────┼─────────────────────────────┘
                                      │
                                      ▼
                              ┌───────────────┐
                              │   Execution   │
                              │    Engine     │
                              └───────────────┘
                                      │
                    ┌─────────────────┼─────────────────┐
                    │                 │                 │
                    ▼                 ▼                 ▼
            ┌───────────────┐ ┌───────────────┐ ┌───────────────┐
            │   Position    │ │   Circuit     │ │    Order      │
            │   Tracker     │ │   Breaker     │ │   Executor    │
            └───────────────┘ └───────────────┘ └───────────────┘
```

### 系统特性

| 特性 | 实现方式 |
|------|----------|
| **零拷贝更新** | `AtomicU64` 打包订单簿数据 |
| **SIMD 加速** | `wide::i16x8` 并行比较 4 种套利类型 |
| **无锁设计** | CAS 循环 (`compare_exchange_weak`) |
| **并发执行** | Tokio 异步运行时 |
| **自动重连** | WebSocket 断线自动重连 |

## 运行时流程详解

### 1. WebSocket 价格更新流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      KALSHI WEBSOCKET HANDLER                                │
└─────────────────────────────────────────────────────────────────────────────┘

     Kalshi WebSocket Message
     ───────────────────────
     │
     ▼
 ┌─────────────────────────────────────────────────────────────────────────┐
 │ Message Type Detection                                                   │
 │ ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐        │
 │ │ book_msg        │    │ trade_msg       │    │ error_msg       │        │
 │ │ (价格更新)       │    │ (成交记录)       │    │ (错误)          │        │
 │ └────────┬────────┘    └─────────────────┘    └─────────────────┘        │
 └──────────┼──────────────────────────────────────────────────────────────┘
            │
            ▼
     ┌─────────────────┐
     │ Parse Message   │
     │ • ticker        │
     │ • yes_price     │
     │ • no_price      │
     │ • yes_size      │
     │ • no_size       │
     └────────┬────────┘
              │
              ▼
     ┌─────────────────────────────────────────────────────────────────────┐
     │ Market Lookup by Ticker Hash                                          │
     │ ─────────────────────────────────────────────────────────────────── │
     │ ticker_hash = fxhash_str(ticker)                                      │
     │ market = state.kalshi_ticker_to_id.get(ticker_hash)                   │
     └─────────────────────────────────────────────────────────────────────┘
              │
              ▼
     ┌─────────────────────────────────────────────────────────────────────┐
     │ Update AtomicOrderbook (Lock-free)                                    │
     │ ─────────────────────────────────────────────────────────────────── │
     │                                                                          │
     │ if both yes and no updated:                                            │
     │     market.kalshi.store(yes_ask, no_ask, yes_size, no_size)            │
     │ else if only yes updated:                                              │
     │     market.kalshi.update_yes(yes_ask, yes_size)  ← CAS loop           │
     │ else if only no updated:                                               │
     │     market.kalshi.update_no(no_ask, no_size)    ← CAS loop             │
     └─────────────────────────────────────────────────────────────────────┘
              │
              ▼
     ┌─────────────────────────────────────────────────────────────────────┐
     │ Check Arbitrage (SIMD-accelerated)                                    │
     │ ─────────────────────────────────────────────────────────────────── │
     │                                                                          │
     │ arb_mask = market.check_arbs(threshold_cents)                          │
     │                                                                          │
     │ ┌──────────────────────────────────────────────────────────────────┐ │
     │ │ check_arbs() in types.rs:176                                       │ │
     │ │ ───────────────────────────────────────────────────────────────  │ │
     │ │ let costs = i16x8::new([                                           │ │
     │ │     p_yes + k_no + k_no_fee,    // Poly YES + Kalshi NO           │ │
     │ │     k_yes + k_yes_fee + p_no,   // Kalshi YES + Poly NO           │ │
     │ │     p_yes + p_no,              // Poly only                      │ │
     │ │     k_yes + k_yes_fee + k_no + k_no_fee,  // Kalshi only         │ │
     │ │     i16::MAX, i16::MAX, i16::MAX, i16::MAX,                       │ │
     │ │ ]);                                                                │ │
     │ │ let cmp = costs.cmp_lt(i16x8::splat(threshold_cents));             │ │
     │ │ // mask bits: [0]=pykn, [1]=kypn, [2]=poly, [3]=kalshi            │ │
     │ └──────────────────────────────────────────────────────────────────┘ │
     └─────────────────────────────────────────────────────────────────────┘
              │
              ▼
     ┌─────────────────────────────────────────────────────────────────────┐
     │ If arb_mask != 0: Send Execution Request                             │
     │ ─────────────────────────────────────────────────────────────────── │
     │                                                                          │
     │ for each bit in arb_mask:                                               │
     │     arb_type = match bit {                                              │
     │         1 => PolyYesKalshiNo,                                           │
     │         2 => KalshiYesPolyNo,                                           │
     │         4 => PolyOnly,                                                  │
     │         8 => KalshiOnly,                                                │
     │         _ => continue,                                                  │
     │     }                                                                   │
     │     exec_tx.send(FastExecutionRequest {                                 │
     │         market_id, yes_price, no_price, yes_size, no_size,             │
     │         arb_type, detected_ns: clock.now_ns(),                          │
     │     }).await                                                             │
     └─────────────────────────────────────────────────────────────────────┘
```

## 套利检测与执行流程

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                      ARBITRAGE DETECTION & EXECUTION                        │
└─────────────────────────────────────────────────────────────────────────────┘

     ┌───────────────────────────────────────────────────────────────────┐
     │                        PRICE UPDATE                                │
     │  Kalshi WebSocket OR Polymarket WebSocket receives new price      │
     └───────────────────────────────┬───────────────────────────────────┘
                                     │
                                     ▼
     ┌───────────────────────────────────────────────────────────────────┐
     │                     UPDATE ORDERBOOK                               │
     │  market.kalshi.update_yes/no() OR market.poly.update_yes/no()     │
     │                    (Lock-free atomic update)                       │
     └───────────────────────────────┬───────────────────────────────────┘
```

**工作原理**:
- 将 4 个 `u16` 值打包进单个 `u64`
- 使用 `AtomicU64::load/store` 进行原子读写
- 部分更新使用 CAS 循环 (`compare_exchange_weak`)

```rust
    use wide::{i16x8, CmpLt};

        i16::MAX, i16::MAX, i16::MAX, i16::MAX,
    ]);

    let cmp = costs.cmp_lt(i16x8::splat(threshold_cents as i16));

}
```

## 总结

该套利交易系统采用了以下高性能设计模式：

1. **无锁数据结构**: `AtomicU64` 打包订单簿，避免锁竞争
2. **SIMD 并行计算**: 单指令检测 4 种套利类型
3. **异步并发**: Tokio 运行时，WebSocket 并行处理
4. **去重机制**: Bitmask 防止同一市场重复执行
5. **风险控制**: 多层熔断保护

**关键性能指标**:
- 套利检测延迟: < 1ms (SIMD 加速)
- 订单簿更新: 零拷贝 (原子操作)
- 并发订单: 同时执行双腿交易
